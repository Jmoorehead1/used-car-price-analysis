# used-car-price-analysis
Machine learning analysis of the factors that influence used car prices using the CRISP-DM framework.

# What Drives the Price of a Used Car?

## Used Car Price Analysis

This project analyzes a dataset of used vehicles to determine which characteristics have the greatest impact on vehicle prices. The analysis follows the CRISP-DM framework and uses exploratory data analysis and regression modeling to identify the factors that used car dealerships should consider when selecting inventory.

## Business Objective

The goal is to identify the vehicle characteristics that are most strongly associated with used car prices and translate the results into actionable recommendations for used car dealerships.
